Role-based Dashboard Navigation (Dynamic Routes via useFactory)

What is this?
This demo navigates to an admin or user dashboard based on the current role. Since the app has no real role system, use the "Switch Role" button to toggle the role stored in localStorage.

How it works:

  • Role is stored in localStorage('role') via AuthService.
  • Switch Role toggles between admin and user (AuthService.setRole()).
  • Go to Dashboard reads the current role and routes to /admindashboard (admin) or /userdashboard (everything else).
  • The two dashboard routes are not in the static routes array. They are created dynamically based on the current role by dashboardRouteFactory(auth) and registered through a useFactory ROUTES multi-provider (with deps: [AuthService]) in AppRoutingModule.

Important — reload required after switching role:

  • The factory runs only once at app startup, so only the route matching the role at boot time is registered (admindashboard for admin, otherwise userdashboard).
  • Switch Role only updates localStorage; it does not re-run the factory or re-register routes.
  • So after switching the role you must do a full page reload (browser refresh, not an in-app navigation) for the newly matching dashboard route to be registered. On reload the app re-bootstraps, the factory runs again, and reads the updated role from localStorage.
