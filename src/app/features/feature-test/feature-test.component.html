Dynamic Routing using useFactory

What is this?
Angular allows routes to be created dynamically at application startup using a factory function (useFactory).

How it works:

  • A factory function runs when the app starts.
  • It checks some condition (e.g., feature flag, role, config).
  • Based on that condition, it dynamically adds or removes routes.
  • Angular registers those routes before the app loads.

This demo:

  • Uses localStorage('beta') as a feature flag.
  • If beta = true → /beta route is added.
  • If beta = false → /beta route does not exist.

Important:

  • Factory runs only once at app startup.
  • Changes require a page reload (F5).
  • This is not reactive like guards.


⚠️ After changing the flag, reload the app to apply new routes.
