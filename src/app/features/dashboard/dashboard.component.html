Angular Route Guards

  • CanActivate – Controls whether a route can be accessed (e.g., only logged-in users).
  • CanActivateChild – Controls access to child routes under a parent route.
  • CanLoad – Prevents a lazy-loaded module from loading if conditions fail.
  • CanDeactivate – Prevents leaving a route (e.g., unsaved form changes).
  • Resolve – Preloads data before the route is activated.
