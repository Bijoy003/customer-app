Remote Dashboard 🚀

This page is loaded from a separate Angular application using Module Federation.

How it works:

  1. User navigates to /remote-dashboard in the shell app
  2. Shell calls loadRemoteModule()
  3. Remote file remoteEntry.js is downloaded from port 4201
  4. Remote exposes DashboardModule
  5. Shell loads and renders it like a local module

Key Concept:

This module is NOT bundled with the main app.
It is fetched at runtime from another app.

✔ Remote loaded from: http://localhost:4201
