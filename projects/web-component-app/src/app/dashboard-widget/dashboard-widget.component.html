Dashboard Widget (Web Component) 🚀

This component is rendered using a Web Component (custom HTML element).

🔹 How it works:

  • This UI is NOT part of the main Angular app.
  • It is loaded from a separate app running on port 4202.
  • A script dynamically registers: customElements.define('dashboard-widget', ...)
  • Once registered, this tag works like a native HTML element.

🔹 Why use this?

  • Independent deployment
  • Reusable across applications
  • Framework-agnostic UI

💡 Key idea: This is a Micro Frontend implemented using Web Components.
